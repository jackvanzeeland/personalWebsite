How should your content map into the new site?

Every piece of existing content is accounted for in both options — nothing is lost, only regrouped. Click the structure you prefer.

A

Consolidated — 5 sections (recommended)

/ — Hero (JVZ formation) + featured work + intro
/work — ALL projects + artifacts in one filterable lattice; each opens a detail view (Wordle solver, Secret Santa, budgeting, basketball, QR, UiPath, HTML gems…)
/journey — About-me bio + skills + career timeline (constellation) + resume download, one narrative page
/beyond — Photos, Instagram, media (unchanged content)
/contact — LinkedIn / GitHub / email / resume (today it's scattered)
Achievements system → becomes a site-wide easter egg (tracker in the corner), not a page

Fewer, stronger destinations = each gets a signature particle formation. Recruiters find everything in one hop. Old URLs 301-redirect to new sections so links/SEO survive.

B

Mirror today's structure — 7 sections

/ — Hero + featured
/projects — project grid + detail views
/artifacts — separate artifact grid (as today)
/about — bio + skills + timeline
/journey — achievements dashboard stays a page
/beyond — photos & media
/contact — new

Familiar structure, URLs mostly keep their meaning, no regrouping decisions. But 7 sections dilute the formations, and projects vs artifacts is a distinction visitors don't care about.
